# yumyum

Le carnet de recettes de La Fabrock — the pocket Moleskine, online.

Each recipe follows the notebook format: ingredients carry a number, ingredients that go in together share it, and the steps refer to them by number — `Melt (1). Add (3) to (2) one by one.`

- `index.html` — the site (search, ingredient finder, A–Z index)
- `recipes.json` — all the recipes

This is the public, read-only copy. New recipes are added in the Claude version of the site, then exported here.
